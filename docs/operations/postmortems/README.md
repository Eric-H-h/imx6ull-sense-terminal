# 运行事故档案

本目录保存服务进入正式或长期运行后，造成实际影响的事故。用途是客观存档和后续审计，不是个人学习笔记。

## 收录条件

至少满足一项：

- 服务中断或持续重启。
- 摄像头、HTTP、motion 或事件日志在运行中长时间不可用。
- 自动恢复、systemd restart 或开机自启未按设计生效。
- 事件丢失、状态错误或性能退化影响演示或长期运行。

开发搭建、驱动探索、接线、构建和普通调试问题进入 [`../../bug_reports/`](../../bug_reports/)。

## 命名规则

```text
INC-YYYYMMDD-NNN_short_slug.md
```
