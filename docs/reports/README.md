# 生成报告

本目录保存可直接在浏览器打开的生成型 HTML 报告：

- `M2_current_progress_report.html`
- `M2_code_learning_manual.html`

这些报告用于阅读和学习，不是当前状态的唯一事实源。M2 状态以 [`plans/current.md`](../plans/current.md)、[M2 evidence](../verification/evidence/M2_mjpeg_stream.md) 和阶段总结为准。

报告站点源代码位于仓库根目录 `tools/report-sites/m2-code-learning-manual/`，不放在 `docs/`。它保留独立 Git 历史并由父仓库整体忽略；父项目只提交本目录中的最终 HTML。
